# Personal Portfolio Website

## About the Project

This project is my personal portfolio website for SWE 363. It introduces
my background as a Computer Science student, shows some of my academic
projects, and includes a contact form.

The website was built using HTML, CSS, and JavaScript. I also made the
layout responsive so it can work on desktop, tablet, and mobile screens.

## Features

- About Me section with a short introduction
- Projects section showing two of my academic projects
- Contact form with Name, Email, and Message fields
- Responsive design for different screen sizes
- Smooth scrolling between sections
- Hover and focus effects
- JavaScript interaction for the contact form

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Grid
- Media Queries

## Projects Included

### KFUPM Parking Reservation System

A parking reservation system prototype designed to help KFUPM users
view parking availability and reserve parking spaces efficiently.

### In-Memory File System Simulator

An in-memory file system simulator developed using OOP and data
structures and algorithms such as HashMaps, trees, DFS, and KMP.

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. No additional installation or backend is required.
