# AI Usage Report

## AI Tool Used

For this assignment, I used ChatGPT as an AI-assisted tool. I mainly used it to help me understand the assignment requirements, organize my portfolio, understand parts of the HTML, CSS, and JavaScript code, and review my work.

## How I Used AI

I used ChatGPT while building different parts of the portfolio. It helped me plan the folder structure and organize the website into the About Me, Projects, and Contact sections.

For CSS, I used it to better understand Flexbox, Grid, media queries, and how to make the website responsive on different screen sizes. I also used it to review the contact form styling and the project card layout.

For JavaScript, ChatGPT helped me understand how to add an interaction to the contact form. I tested the code myself to make sure the confirmation message and form reset worked correctly.

also to help me choose suitable images from my own previous projects instead of using random images. I selected the final prototype from my KFUPM Parking Reservation System and a code screenshot from my In-Memory File System Simulator.

## Benefits and Challenges

Using ChatGPT helped me understand some concepts faster and gave me guidance when I was unsure what to do next. It was also useful for checking my code and explaining why certain HTML, CSS, or JavaScript code was needed.

One challenge was that I still needed to review the suggestions carefully. Not every suggestion needed to be used exactly as given, so I tested the code and changed parts that did not match my project or preferences.

## What I Learned

Through this assignment, I improved my understanding of semantic HTML, CSS Flexbox and Grid, responsive design, media queries, forms, and basic JavaScript event handling. I also learned how to organize a web project into separate folders for HTML, CSS, JavaScript, images, and documentation.

## Responsible Use and Modifications

I reviewed and modified the AI suggestions instead of using everything without checking it.

One example was the About Me section. I combined an AI suggestion with my own academic background and changed the wording to describe myself as a Computer Science student at KFUPM and include the subjects and areas I have studied.

Another example was the Projects section. Instead of using generic placeholder images, I used screenshots from my own academic projects. I also changed the project descriptions so they represented the work I actually completed.

I tested the responsive layout by resizing the browser and tested the contact form myself to make sure the JavaScript interaction worked correctly.
